# 4. WXT Framework with React, TypeScript, and pnpm

Date: 2026-10-03

## Status

Accepted

## Context

We need a modern, maintainable development workflow for our Manifest V3 web extension supporting TikTok, Instagram Reels, and YouTube Shorts. Building extensions with manual Manifest files and ad-hoc bundling often results in friction with content script isolation, HMR, background service worker lifecycles, and TypeScript typings.

## Decision

We will build the extension using **WXT** (Next-gen Web Extension Framework) with **React**, **TypeScript**, and **pnpm**.

- Entrypoints will follow WXT standard conventions (`entrypoints/popup/`, `entrypoints/content/`, `entrypoints/background.ts`).
- Manifest V3 configuration will be auto-generated by `wxt.config.ts`.
- The popup dashboard will be built with React functional components and hooks for clean reactive state.
- Communication between the content script and popup will leverage WXT/Chrome messaging APIs and storage helpers.

## Consequences

- First-class TypeScript support and autocompletion for web extension APIs.
- Hot Module Reloading (HMR) during extension development (`pnpm dev`).
- Reproducible dependency management adhering to the project's standard package manager (`pnpm`).
